# Portfolio scroll redesign

## Objective and problem
Refresh the existing Astro portfolio inspired by the visual rhythm of https://gentlemanprogramming.com while keeping the portfolio's own Spanish content and identity. The current page has static stack pills, no scroll reveal, and navigation inside the hero that scrolls away.

## Scope and constraints
- Reveal information progressively as sections enter the viewport, without hiding content when JavaScript or IntersectionObserver is unavailable.
- Present the existing stack/tools as a continuously moving, accessible horizontal marquee inspired by the reference site's “Agents Gentle-AI configures” strip; do not replace existing technology data.
- Keep navigation visible through scrolling, usable on mobile and desktop, with anchor offsets.
- Preserve the portfolio's original light and dark color tokens, gradients and primary-button colors; the user's follow-up explicitly rejects the reference's palette. Keep readable contrast, Spanish copy, theme toggle, links, and existing portfolio information.
- Honor prefers-reduced-motion for reveal, marquee, and scrolling. Avoid copying source assets or text.
- Organic delegated-direct route: six-plus mapped components, one bounded writer for coordinated multi-file changes. TDD mode: unknown (no project TDD setting found); use ordinary functional checks. Runner: pnpm test -- --run, pnpm lint, pnpm build.
- Forecast ~250–400 authored changed lines; default delivery strategy ask-on-risk if actual work exceeds ~400. No PR requested.
